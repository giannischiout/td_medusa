# Admin Section

This admin section provides a comprehensive interface for managing your Medusa.js store, designed to match the look and feel of the official Medusa.js admin interface.

## Features

- **Dashboard**: Overview of key metrics, recent orders, and quick actions
- **Products**: Manage your product catalog with search and filtering
- **Orders**: View and manage customer orders
- **Customers**: Customer management and insights
- **Analytics**: Performance metrics and reporting
- **Time Slots**: Product scheduling and time slot management
- **Settings**: Store configuration and preferences

## Components

### Layout Components

- `AdminLayout`: Main layout wrapper with sidebar and header
- `AdminSidebar`: Collapsible navigation sidebar
- `AdminHeader`: Top header with search and user menu

### Page Components

- `AdminDashboard`: Main dashboard with stats and recent activity
- Various page components for different admin sections

## Styling

The admin interface uses:

- **Tailwind CSS** for styling
- **shadcn/ui** components for consistent UI elements
- **Lucide React** icons
- **Medusa.js-inspired** design patterns

## Navigation

The sidebar includes navigation to all major admin sections:

- Dashboard
- Products
- Orders
- Customers
- Analytics
- Categories
- Collections
- Discounts
- Shipping
- Regions
- Time Slots
- Reports
- Settings

## Responsive Design

The admin interface is fully responsive and includes:

- Collapsible sidebar for mobile/tablet views
- Responsive grid layouts
- Mobile-friendly navigation
- Touch-friendly interface elements

## Getting Started

Navigate to `/admin` to access the admin interface. The sidebar provides quick access to all admin functions, and the header includes search functionality and user account management.
